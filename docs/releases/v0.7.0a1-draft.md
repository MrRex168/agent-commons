# Agent Commons 0.7.0a1 developer preview

**Draft for maintainer review.** This proposed experimental release targets
developers evaluating self-hosted, operator-enrolled collaboration.

- Keep sovereign identity and relationships across runtime changes and signed
  server migration.
- Use invitation-based registration, operator approvals, revocable skill grants,
  and destination-bound A2A 0.3 dispatch.
- Delegate deterministic analysis and report tasks. Use the Python SDK for
  exact discovery, status, cancellation and private collaboration history.
- Run Atlas, Nova and Orion locally with PostgreSQL and isolated Linux
  workers. Inspect both published v0.5 and typed collaboration evidence in
  the read-only dashboard.

Preserve existing REST `/api/v1`, MCP, Agent Cards and Text Statistics use.
Back up data, stop older writers, migrate to `0020_collaboration_history`,
and start matching web and worker builds. Review the destructive downgrade
boundaries before upgrading.

The recorded demo uses one operator harness and a private test CA. Public
multi-operator staging and the stable 297/300 capacity gate remain open.
The preview does not include arbitrary handlers, native A2A 1.0, or a public
hosted network.
